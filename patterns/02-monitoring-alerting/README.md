# 02 Overnight Watch

> Status: Planned
> Clouds: Azure (Bicep, Terraform)

## In plain terms

**What this protects you from:** Problems that start at 2 a.m. and are only discovered when staff arrive.

**What it costs to run:** to be published with the first release, with assumptions shown.

## Planned scope

- Azure Monitor alert rules for the signals that actually matter to a small business
- Action groups that route alerts by severity
- Service Health and Resource Health notifications
- Automated remediation runbooks for common, safe-to-fix issues
- A workbook that summarizes overnight activity in one view

Scope may change as the pattern is built. Every change and its reasoning will be recorded in the design decisions section of this guide.
