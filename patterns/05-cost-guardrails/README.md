# 05 Cost Guardrails

> Status: Planned
> Clouds: Azure (Bicep, Terraform)

## In plain terms

**What this protects you from:** Surprise bills, forgotten resources, and spending nobody can explain.

**What it costs to run:** to be published with the first release, with assumptions shown.

## Planned scope

- Budgets with tiered alert thresholds
- Tag enforcement so every cost can be traced to an owner
- Policies that block or flag expensive SKUs
- Anomaly alerts for sudden spend changes

Scope may change as the pattern is built. Every change and its reasoning will be recorded in the design decisions section of this guide.
