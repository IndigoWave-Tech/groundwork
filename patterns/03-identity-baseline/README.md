# 03 Identity Baseline

> Status: Planned
> Clouds: Microsoft Entra ID (Terraform)

## In plain terms

**What this protects you from:** Stolen passwords, risky sign-ins, and accounts that outlive the people who used them.

**What it costs to run:** to be published with the first release, with assumptions shown.

## Planned scope

- Conditional Access baseline: MFA, legacy authentication block, risk-based policies
- Break-glass emergency access accounts with monitoring
- Policies deployed in report-only mode first, with a documented path to enforcement
- Named locations and device compliance requirements

Scope may change as the pattern is built. Every change and its reasoning will be recorded in the design decisions section of this guide.
